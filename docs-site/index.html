FluxDrop SDK

Embed verified, peer-to-peer file sends into any web app — the same production wire protocol the FluxDrop app runs on, as an npm package and a zero-framework web component.

1. Install

npm install @fluxdrop/sdk   # or: bun add @fluxdrop/sdk

2. Web component — zero framework

One import registers <fluxdrop-widget>. Shadow DOM, themable, RTL-aware (lang="ar").

<script type="module">
  import '@fluxdrop/sdk/widget'
</script>

<fluxdrop-widget
  signal-url="https://your-fluxdrop-instance"
  endpoint="https://your-fluxdrop-instance"
  accent="#0d9488"
></fluxdrop-widget>

Events: fluxdrop-ready (room + pin + joinUrl), fluxdrop-progress, fluxdrop-complete (verified + file list), fluxdrop-error. React wrapper: import { FluxDropWidget } from '@fluxdrop/sdk/react'.

3. Typed client — full transport

import { createFluxdropClient } from '@fluxdrop/sdk'

const fluxdrop = createFluxdropClient({
  alias: 'docs-site',
  signalUrl: 'https://your-fluxdrop-instance',
})

const room = await fluxdrop.createRoom()
// → share room.roomId + room.pin (QR/link/pigeon)

const { verified } = await fluxdrop.sendFiles([file])
// validate → SHA-256 manifest → pairing → WebRTC DataChannel →
// 64 KiB chunks with ACK pacing + lost-ACK resweep → TRANSFER_COMPLETE
console.log(verified)  // true when every checksum matched on the receiver

5. API surface

ExportWhat it is
createFluxdropClient(options)Typed façade — connect / createRoom / joinRoom / sendFiles / on / destroy
@fluxdrop/sdk/widgetThe <fluxdrop-widget> custom element (auto-registered)
@fluxdrop/sdk/react<FluxDropWidget /> React wrapper around the element
@fluxdrop/sdk/protocol · /encoding · /checksum · /compress · /formatThe engine layer — the app's production wire code, re-exported

6. Compatibility notes

SDK senders are plaintext-over-DataChannel (like the CLI): the receiving FluxDrop app shows its visible E2EE downgrade notice. E2EE (PAKE over the room PIN) stays an interactive web↔web feature. Receivers: any FluxDrop web app v2+ or the worker adapter. Signaling: the Bun server or the Cloudflare Worker adapter.
