## Wire format (exact)
- PREVIEW_REQ (0x10): header `[type:1][transferId:4][chunkIndex=0:4]` + JSON body `{"v":1,"files":[{"i":<fileIndex>,"bytes":24576}, …]}` — first `min(8, files.length)` files.
- PREVIEW_DATA (0x11): header `[type:1][transferId:4][chunkIndex=<fileIndex>:4]` + body = raw head bytes (≤24KB) or `encryptWirePayload(head, 'preview')` envelope (nonce12||GCM ct) when E2E active. AAD kind 'preview' both directions.
